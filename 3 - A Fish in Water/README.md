# A Fish in Water

Salton sea, fusion refil

With the invention of fusion, it was possible to refill the Salton Sea.  The Dead Sea became less dead.

Coleridge wrote the line "Water water everywhere and not a drop to drink."  Today we have the technology to make that water drinkable.  

In the 20th century concerns about desertification and acquifer depletion dominated public thinking.  Now, we can not only reverse that trend, but go further.
